# Regolamento FantaPolitik

Pagina web statica a scorrimento verticale con il regolamento ufficiale della lega.

## Pubblicazione con GitHub Pages

1. Caricare l’intero contenuto di questa cartella nella radice della repository.
2. Su GitHub aprire **Settings → Pages**.
3. In **Build and deployment**, scegliere **Deploy from a branch**.
4. Selezionare il branch `main`, cartella `/(root)`, quindi salvare.

La pagina non richiede compilazione o dipendenze: GitHub Pages userà direttamente `index.html`.
